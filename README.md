# Illuminate Cultural Nutrition - Webpage Clone

A polished, mission-driven static webpage clone of [iculturalnutrition.com](https://iculturalnutrition.com/), transformed from a professional resume into a vibrant lifestyle brand for culturally competent nutrition care.

## 🌟 Overview

This project is a high-fidelity clone of the Illuminate Cultural Nutrition website. It has been enhanced with improved branding consistency, visual identity, and user experience (UX) to better resonate with its mission of "Food Without Shame."

## 🚀 Key Features

- **Cohesive Branding**: Standardized the brand identity as "Illuminate Cultural Nutrition" across the entire site.
- **Enhanced Visuals**: Added high-quality cultural food imagery to reinforce the "Food Without Shame" messaging.
- **Sticky Navigation**: Implemented a sticky header on desktop for constant access to the "Schedule" button and menu.
- **Mobile Optimized**:
  - Click-to-call functionality for all phone numbers.
  - Large, readable fonts and mobile-responsive layout.
- **SEO & Content Ready**:
  - Optimized meta tags and schema data (JSON-LD).
  - Integrated a "Recipe Library" navigation link to support future content marketing.
- **Social Proof**: Enhanced testimonials with authentic-sounding names to build trust.
- **Accessibility**: Added descriptive alt tags for all images and media logos.

## 🛠️ Built With

- **HTML5 & CSS3**: Core structure and styling.
- **Astra & Elementor**: Replicated the original site's layout and design systems.
- **Self-Contained Assets**: All images and CSS files are hosted locally for reliable loading.

## 📖 How to View

To view the webpage, simply open the `index.html` file in any modern web browser:

1. Clone or download this repository.
2. Navigate to the project root.
3. Double-click `index.html` or drag it into your browser window.
